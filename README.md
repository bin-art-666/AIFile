# AIFile

Windows 11 文件管理器。界面复用 Halo 的主题、玻璃背板、文件夹图标及预览组件。打开目录后直接浏览和操作磁盘文件。窗口偏好保存在 `%LOCALAPPDATA%\AIFile\window.json`。

## 构建与运行

在 Windows x64 上运行 `.\build.ps1`。脚本支持 .NET 10 SDK 和 NuGet，也可以指定 `-OfflineTools` 使用本地 SDK 与缓存源。构建完成后双击 `dist\0.2.4\AIFile.exe`，也可把一个目录路径作为启动参数。

- 点击面包屑可返回对应目录。Ctrl+L 可编辑路径，Alt+方向键可前进、后退或返回上一级，F5 刷新。
- 顶栏左侧提供位置栏、目录导航和编辑路径。内容区空白处右键，可以新建、粘贴，或通过「查看」切换列表和网格。
- Ctrl+F 搜索文件名，可选择包含子文件夹、使用本机 OCR 搜索图片文字。结果显示相对路径并可定位。空格预览文件或查看文件夹内前六项。
- Ctrl+C、Ctrl+X、Ctrl+V 使用系统文件剪贴板。F2 重命名，Delete 请求移到系统回收站。
- Windows Shell 负责文件操作与进度。普通删除须经确认，AIFile 拒绝已知无法回收的位置。空白右键可打开系统回收站、查看上次操作的逐项详情以及调整菜单和外观。
- 空白右键开启「手动网格（保留空位）」，拖动卡片只调整显示位置。单项可交换位置，多项保持相对形状。「整理空位」可收拢卡片。
- 在网格内把一个文件拖到另一个文件上停留，看到提示后松手并确认成组。Ctrl+Z 支持符合文件身份校验的整组撤销。

## 隔离验收

`dist\0.2.4\AIFile.exe --verify <绝对报告目录>` 会在指定目录内创建独立测试文件，检查界面、真实目录导航、搜索、Shell 文件操作、手动网格和整组撤销，然后输出 `result.json`。验收只会将其中一个临时文件移到系统回收站。

## Halo 移植记录

以 Halo v0.4.0 的 `bb8980a` 和之前的发布历史为基准。

- `StationDialogs.cs` → `MainWindow.Dialogs.cs`，复用弹窗遮罩、按钮排序、焦点和输入框样式。浏览列表与网格共用这套弹窗处理。
- `SettingsFolderMenu.cs` → `MainWindow.MenuSettings.cs`，复用双层菜单编辑器的操作、预览和自适应排布。在独立窗口的弹窗里沿用文件卡片的鼠标捕获完成同栏排序。
- `ShortcutIcons.cs` → `ShortcutIcons.cs`，复用 Shell 图标提取和转换，接入文件视图和快速预览。
